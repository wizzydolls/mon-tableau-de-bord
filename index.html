Enregistrement automatique dans ce navigateur. Aucune donnée n’est transmise à un service externe. Les appareils ne sont pas synchronisés : exportez puis importez votre sauvegarde pour changer d’appareil. Effacer les données du navigateur peut effacer votre historique. Gardez le fichier exporté dans un endroit privé.

Cette page complète vos habitudes et ne bloque aucune application. Horaires locaux de l’appareil · semaine du lundi au dimanche.

Publier la page et l’installer sur iPhone

Sur GitHub, créez un dépôt public, ajoutez ce fichier sous le nom index.html à sa racine, puis ouvrez Settings → Pages. Choisissez « Deploy from a branch », la branche main et le dossier / (root), puis Save. Une fois le déploiement terminé, ouvrez l’adresse affichée. Seul le fichier de la page est publié : ne mettez jamais votre sauvegarde JSON dans le dépôt.

Sur iPhone, ouvrez cette adresse dans Safari, touchez Partager, puis « Sur l’écran d’accueil » et Ajouter. Utilisez ensuite toujours la même icône pour retrouver vos données. Pour transférer un historique déjà commencé dans Safari, exportez-le puis importez-le dans la page ouverte depuis l’icône. L’accès à la page publiée nécessite une connexion ; vos données restent locales.
